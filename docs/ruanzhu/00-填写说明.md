# 软著材料怎么用

本目录是按 **当前仓库（V1.0 / 程序版本 0.2.10）** 写的登记底稿，给中国版权保护中心「计算机软件著作权登记」用。源程序 PDF 和说明书 PDF 由 `python scripts/build_ruanzhu.py` 生成，输出在 `deposit/`。交件步骤见 `05-交件清单.md`。

| 文件 | 用途 |
| --- | --- |
| `01-申请表信息.md` | 抄到登记系统申请表 |
| `02-主要功能.md` | 申请表「软件主要功能 / 技术特点」栏 |
| `03-软件说明书.md` | 鉴别材料里的**文档**（操作说明） |
| `04-源程序交存说明.md` | 源码前 30 页 + 后 30 页怎么抽 |
| `05-交件清单.md` | 已生成文件与你必须手填的项 |
| `06-申请表怎么填.md` | 身份证、日期、上传材料逐步说明 |
| `deposit/` | 源程序 PDF、说明书 PDF |

## 建议登记名称

- **全称**：育种目标生物逻辑验证系统
- **简称**：Bio-Logic Debugger
- **版本**：V1.0

证书上会印全称和版本。不要只用「让邺城燃烧」当全称，审查员看不懂，也容易被补正。文学名可以写在说明书「软件别名」里。

## 你还要自己补的

1. 开发完成日期、首次发表日期（建议与 GitHub 首次公开日一致）
2. 权利人姓名、身份证、联系方式
3. 说明书里的**界面截图**（说明书已留【截图】占位）
4. 按 `04` 导出源程序 PDF，页眉写成：`育种目标生物逻辑验证系统 V1.0`

## 不要写进申请表的话

- 不要写「未使用 AI」。近年补正和学校通知都盯这个；你实际用过辅助工具，乱承诺有风险。申请表按系统当时要求勾选即可。
- 不要把软著说成专利。登记证明的是**这份程序表达**的权属，不是「育种预筛」这个想法的独占。
- GitHub 开源可以登。开源是许可别人用，著作权仍是你的。

官方入口：中国版权保护中心软件登记。材料格式以当时系统提示为准；源程序一般是前后各连续 30 页、每页不少于 50 行。
