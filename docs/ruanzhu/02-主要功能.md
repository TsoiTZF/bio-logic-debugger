本软件是一套育种目标生物逻辑验证系统。其核心不是替代田间试验，而是在确定育种指标组合之前，用已结构化的生物学知识做可行性预筛，指出「同时追求这些指标」可能违反的关联、约束和历史教训。

软件以育种目标为输入。一条目标包含若干性状项，每项含性状标识、期望数值、比较方向（大于等于、小于等于或等于）和优先级。系统将目标送入验证引擎。引擎按固定管线执行：第一层检查性状是否存在于知识库、目标值是否超出该性状的典型范围；第二层检查目标性状两两之间是否存在负相关或权衡关系，并在用户同时要求双方走高时给出拮抗警告，警告等级由关联强度与置信度共同决定；第三层将约束规则中的条件表达式对照目标数值求值，仅当表达式为真时记为违反，表达式中缺少绑定变量则跳过，避免「只要提到某性状就报警」；第四层将目标性状集合与反模式触发集合做匹配，达到设定相似度时写入历史教训与替代方向；第五层为可选项，在配置接口密钥后调用兼容 OpenAI 协议的大语言模型，生成不重复罗列规则结果的补充评述。管线在出现致命级违反时可提前结束。最终输出验证报告，包括是否建议推进、按致命/严重/警告/提示分级的问题列表、叙事性说明和建议。

知识方面，软件将性状、关联、约束、反模式以 JSON 文件存储。加载时按「用户扩充优先于社区数据、社区数据优先于随包内置数据」合并，并以标识去重。内置数据为水稻示例库，覆盖产量、株型、品质、抗病抗逆、生育期和生理性状。社区数据可从指定仓库同步到本地缓存目录，同步过程不覆盖内置文件。用户可通过文献模块上传 PDF 或按 DOI、标题检索摘要，用规则抽取并可选地用大模型抽取性状、关联和约束，经勾选后写入引擎并允许导出 JSON 以便向社区贡献。

使用方面，软件提供图形界面与命令行两种入口。图形界面用于设定目标、查看报告、浏览性状及其关联、查阅反模式和约束、管理知识库与权重。命令行用于列出性状、查看详情、以及单次或交互式验证。软件在通用微型计算机上依赖 Python 3.10 及以上运行。

## 技术特点（可另栏或接在后面）

1. 领域模型与验证引擎分离：性状、关联、约束、反模式、育种目标、违反记录、验证报告均为独立数据结构，引擎只编排管线。  
2. 约束条件为自研表达式求值，不调用语言动态执行接口，支持比较、与、或、非及括号。  
3. 知识三源合并可测试、可重复；界面不直接读写引擎内部存储，通过公开方法访问。  
4. 规则结果与大模型评述分层，规则层在未配置模型时仍可独立工作。
