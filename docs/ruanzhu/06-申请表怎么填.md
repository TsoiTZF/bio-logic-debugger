# 申请表你怎么填

登记系统入口：中国版权保护中心 → 计算机软件著作权登记。  
下面只写**必须你本人填**的格子。软件名称、功能、源程序量我已经写在 `01-申请表信息.md`，照抄即可。

## 1. 著作权人（自然人）

打开身份证，按下表抄，一个字都不要改。

| 系统里的格子 | 你怎么填 |
| --- | --- |
| 著作权人类型 | 选 **自然人** |
| 姓名 | 身份证上的姓名 |
| 证件类型 | 居民身份证 |
| 证件号码 | 身份证号 18 位 |
| 国籍 | 中国 |
| 省份 / 城市 | 身份证地址所在省、市 |
| 通讯地址 | 能收到纸质证书的地址，建议写现住址，带门牌 |
| 邮政编码 | 对应地址的邮编 |
| 联系人 | 一般就是你自己 |
| 手机 | 你常用的手机号（会收短信） |
| 电子邮箱 | 你常用的邮箱（会收补正通知） |

学校要当权利人：不要填自然人独立开发。改成学校（或你和学校共有），并按学校科研处要求交职务作品证明 / 合作开发协议。

## 2. 日期

| 格子 | 建议 |
| --- | --- |
| 开发完成日期 | 填 **2026-09-13**（当前版本定稿日）。你若记得更早做完，填你认定的那天，不要晚于申请日。 |
| 首次发表日期 | 代码已在 GitHub 公开。仓库最早提交是 **2026-05-31**。若那天已经公开仓库，就填 2026-05-31；若更晚才公开，填实际公开日。 |
| 发表状态 | 选 **已发表** |
| 发表地点 | 可填 **互联网** 或 **GitHub**（以系统选项为准） |

两日期都不要填申请当天的未来日期，也不要完成日期晚于首次发表（若已发表，完成日应 ≤ 发表日；若你认为 9 月才算完成、5 月只是草稿，就把首次发表改成你真正公开可用版本的那天，例如 2026-09-13）。

**更稳妥的一组：**

- 开发完成日期：2026-09-13  
- 首次发表日期：2026-09-13  
- 发表状态：已发表  

这样不会出现「5 月就发表、9 月才完成」的矛盾。
